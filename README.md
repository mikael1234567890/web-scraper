# Book Scraper

Automatiserad Python-webbscraper för [Books to Scrape](https://books.toscrape.com).  
Projektet samlar information om böcker, spårar förändringar och skickar **real-tids-notiser till Discord** när nya böcker dyker upp.

---

## Funktioner

- Hämtar boktitel, pris och URL  
- Sparar resultaten i `books.json` med versionshistorik  
- Upptäcker automatiskt nya böcker  
- Skickar Discord-notiser när nya böcker hittas  
- Fullt automatiserat med GitHub Actions  
- Kan köras manuellt eller enligt schema  

---

## Teknologi

- Python 3.11  
- Requests  
- BeautifulSoup4  
- GitHub Actions för automation och CI/CD
